# CLI 사용량 제한 시 운영 규칙

공통 권한·문서 정책은 AGENTS.md와 [실행 계약](../../agents/ORCHESTRATION.md)을 따른다.

- quota/rate limit이면 현재 실행은 INCOMPLETE다. 독립 검증 미실행을 다른 역할의 결과로 PASS 처리하지 않는다.
- 대상 SHA·실행 중 세션·마지막 명령·알려진 retry/reset 정보는 Git ignore 대상 런타임 상태 또는 임시 디렉터리에 둔다. 모르는 값은 추정하지 않는다. 영구 진행·인계 보고서는 만들지 않는다.
- production 코드·Git 상태를 되돌리거나 모델·인증 방식을 자동 대체하지 않는다. 구독 인증을 우선하고 API 과금이 필요한 경우 사전 승인받는다.
- 중단 후 GitHub Issue/PR과 실제 세션·브랜치 상태를 대조한다. 이미 진행 중이거나 성공 여부가 불확실한 실행을 중복 호출하지 않는다.
- 재개는 Architect의 원인·상태 판단과 현재 사용자 승인 범위를 따른다. reset 전 자동 반복·예약 등록·과거 예약 재활성화를 하지 않는다.

과거 예약의 로컬 JSON은 실행 중인 외부 scheduler 상태의 증거가 아니다. 이 규칙은 외부 예약을 생성·변경·해제하지 않는다.
