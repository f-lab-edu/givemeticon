## 문서 상태를 고쳐 읽어야 하는 곳

- docs/architecture/RABBITMQ_MIGRATION_EVIDENCE_INDEX.md: #165/#176 미병합, #167 검토 대기, producer Pending이라는 기록은 후속 #165/#176/#182/#183 병합과 다르다.
- docs/agent-run/STATUS.md: Latest checkpoint의 calibration in_progress는 현재 API의 completed/success로 바뀌었다. 그 SUCCESS는10k baseline PASS가 아니다.
- ADR004 표제 candidate awaiting Verifier는 #182 이전 상태이며, destroy 후 slot 일괄 해제는 merged core의 현행 코드다. local b806db2의 unknown 보존으로 아직 바뀌지 않았다.
- ADR005/issue-184-review의 inline 메타 증감은 #185 시점. #186/#188의 snapshot 계약에 재사용하지 않는다.
- 루트 미추적 docs/tasks/README는 #170/#177 로컬 진행을 복원하는 보조 자료지만 현재 원격 상태·기한의 권위 있는 실시간 index는 아니다.
- 과거 Issue 본문의 Architect 병합 위임이나72시간 timer는 현재 workflow의 자동 병합 금지·새 작업 권한을 대체하지 않는다.

PR #181/#183/#186/#188의 submitted reviews API는 각각0건이었다. PR 본문의 보고, 로컬 독립 검토, CodeRabbit 자동 안내 댓글을 GitHub 승인 리뷰로 합치지 않는다.

기존 문서를 덮어쓰지 않고 이 대조를 추가했다. PR merge≠독립 검증, CI SUCCESS≠모든 integration 실행이다. 기본 test는 integration tag를 제외한다.
